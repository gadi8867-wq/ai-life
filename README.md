# AI Life 🌍

Автономный 3D-мир с двумя наблюдаемыми AI-персонажами — Альфой и Бетой.

## Сейчас умеет
- 3D-мир в браузере на Three.js
- автономное перемещение персонажей
- состояния: исследование, поиск еды, отдых, изучение
- встречи и диалоги
- облачка реплик и журнал последних диалогов
- подсветка персонажей во время встречи
- русская озвучка через SpeechSynthesis браузера
- мобильное управление камерой жестами
- наблюдение за Альфой/Бетой и автокамера
- пауза и ускорение времени

## Запуск
Открой `index.html` в современном браузере. Интернет нужен для загрузки Three.js с CDN.

## Идея проекта
Человек не управляет персонажами напрямую. Он наблюдает за самостоятельной жизнью мира. Следующий этап — отделить симуляцию, память, потребности, экономику, строительство и более серьёзную автономную AI-архитектуру, чтобы мир мог жить длительно.
